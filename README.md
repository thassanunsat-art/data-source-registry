# ทะเบียนแหล่งข้อมูล

เว็บสำหรับค้นหาและเรียกดูแหล่งข้อมูลสถิติภาครัฐไทย 44 ชุดข้อมูล จัดกลุ่มตาม 6 มิติ — ข้อมูลพื้นฐาน สุขภาพ สังคมและเศรษฐกิจ สิ่งแวดล้อมและโครงสร้างพื้นฐาน การศึกษาและพัฒนาศักยภาพ และการมีส่วนร่วมของประชาชน

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องใช้เซิร์ฟเวอร์

- พิมพ์ในช่องค้นหาเพื่อกรองตามชื่อชุดข้อมูล หน่วยงาน ปี ระดับพื้นที่ หรือคำสำคัญ
- กดแถบมิติด้านบนเพื่อกระโดดไปยังกลุ่มที่ต้องการ
- คลิกการ์ดเพื่อดูรายละเอียดเต็มและลิงก์ไปยังแหล่งข้อมูลจริง

## แต่ละรายการมีอะไรบ้าง

ช่วงปีข้อมูล · ระดับพื้นที่ · ความถี่การอัปเดต · รูปแบบไฟล์ · หน่วยงานเจ้าของ · วิธีการคำนวณ · ลิงก์แหล่งข้อมูล

## ข้อควรทราบ

ข้อมูลในทะเบียนนี้เป็นการรวบรวมเพื่อชี้เป้าว่าจะหาข้อมูลได้จากที่ใด ควรตรวจสอบปีล่าสุดและเงื่อนไขการใช้งานกับหน่วยงานเจ้าของข้อมูลก่อนนำไปอ้างอิง

บางรายการมีป้าย "ลิงก์ที่ค้นเพิ่ม" กำกับ หมายถึงลิงก์ที่ค้นหามาเติมภายหลัง ไม่ได้อยู่ในแหล่งรวบรวมตั้งต้น
